# Eita nóis · estúdio de conteúdo

Plataforma da equipe de social media: post em vídeo (briefing, revisão com linha do tempo e entrega), estáticos com ajustes de imagem, motion graphics com linha do tempo e saída transparente, legenda dinâmica, projetos, quadro da equipe, calendário, oportunidades, acervo, Search Lab, insights e marcas criadas pela própria equipe.

- Roda inteira no navegador (Google Chrome). Os vídeos são lidos direto do computador de quem usa.
- A chave da API fica só no navegador de quem cola em Configurações.
- Fontes e logos licenciados das marcas não vão pro repositório: ficam salvos no navegador.

## Motion

Ícones de traço: Lucide (ISC). Ícones 3D: Fluent Emoji, da Microsoft (MIT). Carregados do jsDelivr na hora do uso.

Biblioteca de fontes: Google Fonts (variáveis) e Annotation Mono (OFL).
